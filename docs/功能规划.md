# 产品功能规划 —— 小佳佳的生活日记

> 定位：**私人生活记录 + 美妆成长 + 灵感收藏 + 私密健康空间**
> 核心不是"管理"，而是**陪伴和记录**。
> 目标体验：「她每天愿意打开一下的小天地」—— 记录 → 沉淀 → 回顾 → 发现自己变好 → 偶尔生成可分享内容。

---

## 一、信息架构（5 Tab + 中央加号）

| Tab | 内容 |
| --- | --- |
| 🏠 首页 | 今日问候 / 最近记录 / 灵感 / 私密入口 |
| 📔 记录 | 日记 / 照片 / 心情 / 时间线 |
| ＋（中央悬浮） | 快速记录：写日记 / 记妆容 / 拍照片 / 记想法 |
| 💄 美妆 | 化妆技巧 / 美妆柜 / 好物 / 种草 |
| ❤️ 收藏 | 灵感 / 好物 / 喜欢的记录 |
| 👩 我的 | 个人设置 / 数据统计 / 分享设置 / 隐私设置 |

核心原则：**记录要足够快** —— 打开网站 → 点 + → 10 秒内开始记录。

---

## 二、功能模块

### 1. 首页（每天打开的地方）
- **今日问候**：每天随机一句轻松的话，可按星期变化（周一"新的一周，慢慢来"、周五"今天可以奖励自己一下"）
- **「今天想记录什么？」**：4 个快捷入口（写日记 / 记录妆容 / 拍张照片 / 记个小想法），点击直达对应编辑器
- **今日小惊喜**：每天随机出现的一句话（夸夸、纪念日、悄悄话），让网站从"工具"变成"男朋友做的小东西"

### 2. 日常记录（核心）
小红书 + 私人日记的混合形态。一条记录包含：
- 标题、正文、图片/视频、标签
- **心情**（8 选 1）：开心 / 幸福 / 平静 / 委屈 / 难过 / 生气 / 好困 / 有成就感
- 天气、地点（可选）
- 支持按月回顾心情统计（"这个月开心 12 次"）

### 3. 照片日记
- 每天最多一张/几张：今日自拍 / 穿搭 / 妆容 / 美食 / 天空 / 小确幸
- 长期沉淀后可生成「我的 2026」照片长卷

### 4. 美妆技巧库
- 分类：底妆 / 眉毛 / 眼妆 / 睫毛 / 腮红 / 修容 / 唇妆 / 卸妆 / 护肤 / 发型 / 穿搭
- 每篇：图片、步骤、使用产品、注意事项、适合场景、我的评价
- **「我试过了」**：记录尝试日期、效果星级、下次想调整的点 —— 知识库变成个人成长记录

### 5. 美妆柜 / 好物库
- 记录拥有的产品：图片、名称、色号、价格、购买时间、使用感受、喜欢程度、是否回购
- **使用记录**：今天用了哪些产品 → 自动统计"本月最常用的 5 个产品"

### 6. 种草清单
- 想买的东西清单，状态流转：**想买 → 已购买 → 已使用 → 不推荐**
- 形成种草 → 购买 → 使用 → 评价的完整闭环

### 7. 小红书内容助手
- 记录完成后一键「生成小红书」：自动生成标题、正文、标签（#新手化妆 #日常妆…）
- 支持复制文案、生成图片排版
- 不需要"写完日记 → 复制 → 重新整理"

### 8. 可见范围（内容工作流）
每篇内容四种状态：
🔒 仅自己 → 💗 私人收藏 → 🌸 准备分享 → 📕 已发布
形成自然工作流：随手记录 → 整理 → 分享 → 发布

### 9. 灵感收藏（私人 Pinterest）
- 收藏妆容 / 穿搭 / 发型 / 家居 / 美食 / 摄影 / 文案 / 小红书笔记
- 打标签管理（眼妆 / 穿搭 / 拍照 / 文案 / 旅行）

### 10. 私密空间（完全隔离）
- 首页只显示入口：「🔒 专属私密空间 —— 有些东西，只属于你自己。输入密码进入」
- **绝不显示任何具体健康数据**
- 进入后：身体记录 / 经期记录 / 体重记录 / 私密日记 / 隐私设置

#### 10.1 体重记录
- 记录：日期、体重、备注
- 趋势：7 天 / 30 天 / 3 个月 / 1 年
- 理念：认识自己的身体，而不是要求自己变成某个数字

#### 10.2 经期记录
- 记录：开始/结束日期、周期、感受、症状、备注
- 展示："经期第 2 天 · 状态：有点累 · 早点休息"
- 定位是个人记录与周期回顾，**不是医疗诊断产品**

#### 10.3 私密日记
- 与普通日记隔离，🔒 仅自己可见
- 支持「一键隐藏」：离开页面后需重新输密码

#### 10.4 自动锁定（重要隐私功能）
- 5 分钟无操作 / 切换 Tab / 关闭页面 / 进入后台 → 重新验证密码

### 11. 回顾系统
- **成长时间线**：自动从记录中提取"第一次"（第一次化妆、第一次旅行…）→「我变得越来越好的证据」
- **月度回顾**：「我的 9 月」—— 记录 18 次 / 收藏 12 个灵感 / 尝试 6 个妆容 + 高频关键词 + 照片 → 生成"9 月生活小报"
- **周年回顾**：「我的 2026」—— 365 张照片 / 87 条记录 / 32 次妆容尝试 → 漂亮的时间轴

## 三、使用闭环

```
闭环一（留存）：
今天 → 打开网站 → 「今天想记录什么？」
     → 日记 / 妆容 / 照片 → 自动归档 → 收藏/标签
     → 生活知识库 → 月度/年度回顾 → 「原来我变了好多」→ 持续回来

闭环二（分享）：
日常记录 → 整理成内容 → 生成小红书文案 → 生成图片 → 复制/发布
```

最终形态：**她的私人生活数据库 + 美妆知识库 + 内容创作助手 + 成长相册**。

## 四、优先级路线图

### P0 —— MVP（第一版只做这 7 个）
| # | 功能 | 现状 |
| --- | --- | --- |
| 1 | 首页（今日问候 + 快速记录入口） | 🟡 有静态版，需加问候语与动态数据 |
| 2 | 快速记录（+ 编辑器） | ❌ 仅底部面板入口 |
| 3 | 日记 / 图片记录（含心情/标签） | 🟡 有静态列表，缺编辑与数据层 |
| 4 | 美妆技巧库 | 🟡 有静态卡片墙 |
| 5 | 美妆柜 / 好物收藏 | ❌ 未开始 |
| 6 | 私密空间（真实功能） | 🟡 有密码门 + 静态展示 |
| 7 | 密码 + 自动锁定 | 🟡 有密码门，缺自动锁定 |

### P1（第二梯队）
8. 小红书内容生成
9. 种草清单
10. 灵感收藏（打标签、分类）
11. 月度回顾

### P2（第三梯队）
12. AI 整理日记
13. AI 生成小红书
14. 年度回顾
15. 成长时间线
16. **今日小惊喜**（必留！前面解决"有没有用"，这个解决"为什么她会喜欢"）
17. 情侣专属内容

## 五、数据模型草案

```
Record        记录（日记/照片/想法共用）
  id, type(diary|photo|idea), title, content, images[]
  mood, weather, location, tags[], visibility(仅自己|私人收藏|准备分享|已发布)
  createdAt

BeautyTip     美妆技巧
  id, category, title, cover, steps[], products[], notes, scene, rating
  triedAt?, triedEffect?, nextAdjust?     ← 我试过了

Product       美妆柜产品
  id, name, brand, shade, price, image, boughtAt
  review, favor(1-5), repurchase(bool)

UsageLog      使用记录
  id, productId, date

Wish          种草清单
  id, name, image, note, status(want|bought|used|notRecommend)

Inspiration   灵感收藏
  id, type(妆容|穿搭|发型|家居|美食|摄影|文案|笔记)
  image, note, tags[]

PrivateLog    私密数据
  WeightLog:  id, date, weight, note
  PeriodLog:  id, start, end, symptoms[], feeling, note
  PrivateDiary: id, date, content, mood

Surprise      今日小惊喜（P2）
  id, type(text|photo|anniversary), content, date?
```
