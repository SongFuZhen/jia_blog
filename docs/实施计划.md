# 实施计划（P0 → P1 → P2）

> 对应《功能规划.md》。当前代码库状态：静态原型已完成（首页 + 7 个页面 + 设计 Token + 霞鹜文楷），全部为 mock 数据，无数据层。

## 〇、技术基座（P0 前置）

| 决策 | 方案 |
| --- | --- |
| 数据层 | MVP 用 **localStorage + Zustand persist**（零后端、10 秒记录闭环优先）；P2 迁移 SQLite/云数据库 |
| 状态管理 | Zustand（每模块一个 store：records / beauty / private / settings） |
| 编辑器 | 快速记录用 BottomSheet 内嵌表单；照片用 `<input type="file">` 转 base64/IndexedDB |
| 自动锁定 | 全局监听 `visibilitychange` + 5 分钟 idle 计时器，私密 store 加 `locked` 状态 |
| 路由 | 现有 App Router 页面改造为读 store；新增 `/record/[id]` 编辑页、`/cabinet`、`/wish`（P1） |

## 一、P0 实施顺序（7 步）

1. **数据层搭建**：Zustand store + localStorage 持久化 + 类型定义（Record/BeautyTip/Product/WeightLog/PeriodLog）+ seed mock 数据迁移
2. **快速记录编辑器**：BottomSheet 升级为真实表单（标题/正文/心情/天气/标签/图片）→ 写入 store → 10 秒闭环
3. **首页动态化**：今日问候（按星期+随机）、「今天想记录什么」接编辑器、最近更新读真实 records、心情统计卡
4. **日记页改造**：读真实数据、按月分组、心情筛选、记录详情/编辑/删除
5. **美妆技巧库**：分类导航、技巧详情（步骤/产品/注意事项）、「我试过了」记录
6. **美妆柜**：产品 CRUD + 使用记录打卡 + 本月常用 Top5
7. **私密空间完善**：体重/经期记录表单 + 趋势图（简单 SVG 折线）、私密日记、**自动锁定**（5 分钟 idle + Tab 切换）

## 二、P1（数据层就绪后）

8. 小红书内容生成（模板拼接，非 AI）
9. 种草清单（状态流转看板）
10. 灵感收藏升级（分类标签筛选、收藏来源）
11. 月度回顾（聚合统计 + 生活小报排版）

## 三、P2（远期）

12-14. AI 整理/生成（接 LLM API）
15. 成长时间线（从记录自动提取"第一次"）
16. **今日小惊喜**（后台维护文案库，首页随机出现）
17. 情侣专属内容（隐藏入口 + 纪念日）

## 四、验收标准（P0）

- [ ] 打开网站 → 点 + → 10 秒内发出一条带心情的记录，刷新后不丢
- [ ] 日记/美妆/首页全部读真实数据，无 mock 残留
- [ ] 私密空间 5 分钟无操作或切 Tab 后自动上锁
- [ ] 体重/经期可添加记录并看到趋势
